# 第五週學習計畫：集合框架深化與多表關聯實務 (5/11 - 5/15)

## 📌 本週目標
1. **Java Map 體系**：深入理解 `HashMap` 的實作原理（Hash 碰撞、陣列+鏈表/紅黑樹），並學會區分 `TreeMap` 與 `LinkedHashMap`。
2. **SQL 多表關聯 (Joins)**：掌握 `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN` 的差異，處理複雜的醫療資料跨表查詢。
3. **演算法進階**：正式進入「滑動視窗 (Sliding Window)」實戰，解決長度不固定的子字串/子陣列問題。
4. **Side Project**：實作「醫院跨科別統計儀表板」。

---

## 📅 每日詳細計畫

### 5/11 (週一)：HashMap 核心原理
*   **Java**：`HashMap` 的底層結構、`put()` 與 `get()` 的執行邏輯。
*   **實作**：手寫一個簡單的 `Hash` 統計工具，模擬資料存放過程。
*   **關鍵點**：理解為什麼 `Key` 必須重寫 `hashCode()` 與 `equals()`。

### 5/12 (週二)：Map 家族對比與應用
*   **Java**：`HashMap` (快) vs `TreeMap` (排序) vs `LinkedHashMap` (保留順序)。
*   **實作**：使用 `LinkedHashMap` 實作一個簡單的 LRU 快取機制。

### 5/13 (週三)：SQL 多表關聯基礎 (Inner/Left Join)
*   **SQL**：學習如何將 `Doctor` 表與 `Department` 表關聯。
*   **場景**：統計「各科別的所有醫師清單」，包含那些目前沒有醫師的科別 (Left Join)。

### 5/14 (週四)：滑動視窗演算法入門
*   **LeetCode**：#3 Longest Substring Without Repeating Characters (滑動視窗經典題)。
*   **技巧**：理解 `left` 與 `right` 指針如何伸縮來維持視窗有效性。

### 5/15 (週五)：週總結與綜合實戰
*   **實戰**：擴充醫院系統，產出一份包含「醫師姓名、所屬科別、當月看診人數、總收入」的綜合統計報表（需用到 Join + Group By）。
*   **總結**：填寫進度表、撰寫週心得。
