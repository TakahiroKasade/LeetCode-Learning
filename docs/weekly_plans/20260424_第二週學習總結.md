# 第二週學習總結報告 (2026/04/20 - 2026/04/24)

## 🎯 核心學習成果

### 1. Java 物件導向 (OOP)
*   **封裝 (Encapsulation)**：成功理解為何屬性要 `private`，並透過 `Getter/Setter` 實作資料驗證邏輯。
*   **建構子 (Constructor)**：掌握了 `this()` 鏈的用法，減少重複代碼，並理解物件初始化的過程。
*   **靜態 (Static)**：學會區分「類別變數」與「實體變數」，成功實作自動流水號生成器 (`S001`)。
*   **記憶體模型 (Memory Model)**：理解 Stack (引用) 與 Heap (實體) 的關係。這是本週最燒腦的部分，但也是轉職資深工程師的關鍵。

### 2. SQL 進階
*   **複雜聯結 (Multiple JOINs)**：已能處理三張表以上的聯結，模擬 HIS 系統中的跨部門資料查詢。
*   **子查詢 (Subquery)**：理解 WHERE 中巢狀 SELECT 的邏輯。
*   **集合運算 (UNION)**：學會合併結果集。

### 3. LeetCode 實戰
*   **Q13, Q155**：表現優異，對物件狀態的維護有深刻體會。
*   **Q206, Q707**：目前處於「半理解」狀態。Linked List 的引用變換 (Reference Swapping) 需要更多時間進行畫圖模擬。
