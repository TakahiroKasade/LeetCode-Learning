## 📌 本週目標
1. **Java 核心**：掌握物件導向 (OOP) 的基礎概念（類別、封裝、建構子、Static、記憶體模型）。

3. **演算法實戰**：透過 LeetCode 5 題驗證 OOP 概念理解深度，強化設計思維。
4. **實務應用**：模擬 HIS 系統中的病人管理與住院統計邏輯。

### 4/20 (週一)：類別與物件、記憶體模型、Subquery、LeetCode #13

**上午 (Java - Class & Object)**
- 觀念：藍圖 (Class) vs 實體 (Object) 的記憶體關係
- 手寫：`Patient.java` (定義姓名、病歷號、年齡)
- 實作：編譯並建立 3 個 Patient 物件

**中午 (Memory Model - 新增核心課程)**
- 觀念講授：Heap 上的物件存儲 vs Stack 上的引用指針
- 堆棧圖練習 1：單物件引用
  ```java
  Patient p1 = new Patient("Alice", "P001", 30);
  ```
  ➜ 在紙上畫出 Stack 上的 p1 引用，Heap 上的 Patient 物件

- 堆棧圖練習 2：多物件與引用重新指向
  ```java
  Patient p1 = new Patient("Alice", "P001", 30);
  Patient p2 = p1;
  Patient p3 = new Patient("Bob", "P002", 25);
  p2 = p3;
  ```
  ➜ 畫出每一步後的堆棧圖，標註物件身份與引用關係

- 堆棧圖練習 3：物件陣列的記憶體佈局
  ```java
  Patient[] patients = new Patient[3];
  patients[0] = new Patient("Alice", "P001", 30);
  ```

**下午 (SQL - Subquery)**
- [x] 子查詢 (Subquery) 入門 —— 在 WHERE 中使用 SELECT
- [x] 題目 1：查詢所有住院天數 > 平均住院天數的病人
- [x] 題目 2：在 FROM 中使用子查詢，篩選平均年齡 > 50 的科別

### 4/21 (週二)：封裝與資料安全、多表 JOIN、LeetCode #206

**上午 (Java - Encapsulation)**
- 觀念：`private` 修飾詞與 `Getter/Setter` 的必要性
- 任務：實作資料驗證（例如：生命徵象數值必須在合理範圍內）
- 重構 `Patient.java`：加入 private 變數與驗證邏輯
  ```java
  private int temperature;  // 體溫
  public void setTemperature(int temp) {
      if (temp < 35 || temp > 42) {
          throw new IllegalArgumentException("體溫異常");
      }
      this.temperature = temp;
  }
  ```
- 實作 `Doctor.java` 的 Encapsulation

**下午 (SQL - Multiple JOINs)**
- 多表 JOIN 實務：Person / Address / Hospital / Department / Orders 五表聯結
- 題目 1：兩表 JOIN - 查詢所有患者的姓名與住址
- 題目 2：三表 JOIN - 查詢每間醫院、每個科別的掛號人數
- 題目 3：四表 JOIN (HIS 進階) - 查詢患者、科別、醫生、醫院的完整聯結

**下午 (LeetCode)**
- #206 Reverse Linked List (Easy) ✨ [重點複習對象：邏輯需多次模擬]
