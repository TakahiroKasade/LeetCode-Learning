# 第四週學習計畫：異常處理與集合框架深化 (5/04 - 5/08)

## 📌 本週目標
1. **Java 異常處理 (Exception Handling)**：掌握 Try-Catch-Finally 機制，區分 Checked vs Unchecked Exception，並學習如何撰寫自定義異常。
2. **Java 集合框架進階**：深入理解 `List` 介面，比較 `ArrayList` 與 `LinkedList` 的底層原理與使用場景。
3. **SQL 資料統計與分組**：學會使用聚合函數 (COUNT, SUM, AVG) 與 `GROUP BY`、`HAVING` 子句，處理報表級別的查詢。
4. **演算法實戰**：徹底解決 Linked List 循環問題 (#141, #142)，並進入「滑動視窗 (Sliding Window)」入門。
