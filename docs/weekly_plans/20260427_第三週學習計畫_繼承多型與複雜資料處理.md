# 第三週學習計畫：繼承多型與複雜資料處理 (4/27 - 5/01)

## 📌 本週目標
1. **Java 進階 OOP**：掌握繼承 (Inheritance)、多型 (Polymorphism)、抽象類別 (Abstract Class) 與介面 (Interface)。
2. **SQL 交易管理**：學習 DML (INSERT/UPDATE/DELETE) 與交易控制 (COMMIT/ROLLBACK)，模擬醫療系統的資料一致性。
3. **演算法實戰**：攻克雙指針 (Two Pointers) 與 Linked List 進階題型。
