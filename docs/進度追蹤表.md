### 題目：Two Sum (LeetCode #1)
**完成日期：** ____

**解題思路：**
```
第一次嘗試：暴力法 O(n²) - 時間過長
優化：使用 HashMap 存儲數值和索引
- 邊遍歷邊查表
- 時間：O(n)，空間：O(n)
```

**Java 代碼：**
```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[] { map.get(complement), i };
            }
            map.put(nums[i], i);
        }
        return new int[] {};
    }
}
```

**關鍵知識點：**
- ✓ HashMap 的基本操作
- ✓ 一次遍歷的想法
- ✓ 邊界處理

**容易出錯的地方：**
- ❌ 忘記返回索引而不是值
- ❌ 重複元素的處理

**後續改進：**
- [ ] 練習用 Two Pointers 解決排序數組的情況

## 常見錯誤記錄

### Java 相關
```
❌ 錯誤1：在 HashMap 中使用 NullPointerException
✓ 解決：先檢查 containsKey() 再使用 get()

❌ 錯誤2：LinkedList 和 ArrayList 混淆
✓ 解決：理解各自的時間複雜度
  - ArrayList 查詢快 O(1)，插入慢 O(n)
  - LinkedList 查詢慢 O(n)，插入快 O(1)

❌ 錯誤3：遞歸時忘記 base case
✓ 解決：遞歸題一定要先寫終止條件
```

### SQL 相關
```
❌ 錯誤1：GROUP BY 後使用 WHERE 代替 HAVING
✓ 解決：
  - WHERE 用於分組前篩選
  - HAVING 用於分組後篩選

❌ 錯誤2：JOIN 後得到笛卡爾積
✓ 解決：檢查 ON 條件是否正確

❌ 錯誤3：忘記使用 DISTINCT 導致重複
✓ 解決：查詢前想清楚是否需要去重
```
