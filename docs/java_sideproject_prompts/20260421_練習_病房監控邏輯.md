### 🧠 核心邏輯模組：資料格式相容性轉換 (Flattened CSV to Grid)
*   **學習背景**：學會了將資料庫存儲的扁平 CSV 字串轉換為群組化結構，並處理新舊版本資料的相容性。
*   **關鍵邏輯**：
    1.  判斷輸入字串的長度（Legacy 3筆 vs Detailed 12筆）。
    2.  將資料映射到 `double[3][4]` 的二維網格中。
    3.  處理 `split` 的空值問題與陣列越界保險機制。

### 📝 出題要求
1.  **情境設計**：請沿用「智慧病房監控系統」場景，紀錄 3 組生命徵象（體溫、脈搏、血壓）。
2.  **資料格式**：
    *   **舊格式 (Legacy)**：長度 3，例如 `"36.5,80,120"`。
    *   **新格式 (Detailed)**：長度 12，例如 `"36.5,36.6,36.4,36.5,80,82,79,81,120,121,119,120"`。
3.  **任務目標**：
    *   寫出格式判定邏輯。
    *   如果是舊格式，將唯一值填入網格的第一個位置，其餘補 0。
    *   如果是新格式，使用迴圈與座標公式將 12 筆資料正確填入 [3][4] 網格。
4.  **輸出限制**：
    *   ❌ 禁止提供代碼。
    *   ✅ 請提供題目描述、範例資料字串、以及實作時的邏輯陷阱提示。
