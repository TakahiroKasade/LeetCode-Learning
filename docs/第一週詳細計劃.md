**Java 模板代碼（遮住再看哦！）**
```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // 創建 HashMap 來存儲 (數字, 索引)
        Map<Integer, Integer> map = new HashMap<>();
        
        // 遍歷數組
        for (int i = 0; i < nums.length; i++) {
            // 計算補數（需要的另一個數）
            int complement = target - nums[i];
            
            // 檢查補數是否已經在 map 中
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            
            // 把當前數字加入 map
            map.put(nums[i], i);
        }
        
        // 沒找到就返回空陣列
        return new int[]{};
    }
}
```

#### 9:10-9:50 | 新題目：LeetCode #20 - Valid Parentheses (40 分鐘)

**難度：** Easy  
**預計時間：** 30-40 分鐘

**題目講解：**
```
題目：判斷括號序列是否有效

有效的情況：
- ()
- ()[]{}
- {[]()}

無效的情況：
- (]
- ([)]
- {[}

規則：
1. 括號必須正確配對
2. 內層括號要在外層括號關閉前關閉
3. 每個閉括號都對應一個開括號

解題思路：
→ 用棧 (Stack)！
→ 遇到開括號就入棧
→ 遇到閉括號就檢查棧頂
```

**Java 代碼框架：**
```java
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();
        
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                // 開括號入棧
                stack.push(c);
            } else {
                // 閉括號處理
                if (stack.isEmpty()) return false; // 沒有配對
                
                char top = stack.pop();
                // 檢查是否匹配
                if ((c == ')' && top != '(') ||
                    (c == ']' && top != '[') ||
                    (c == '}' && top != '{')) {
                    return false;
                }
            }
        }
        
        return stack.isEmpty(); // 檢查是否全部配對
    }
}
```

#### 9:10-9:50 | 新題目：LeetCode #9 - Palindrome Number (40 分鐘)

**難度：** Easy

**題目講解：**
```
判斷一個整數是否是迴文數

例：
121 → true (反轉也是 121)
-121 → false (負數不是迴文)
10 → false (反轉是 01，不等於 10)

方案 1：轉字符串
方案 2：數學方法（反轉數字）
```

**Java 代碼（轉字符串方案）：**
```java
class Solution {
    public boolean isPalindrome(int x) {
        String s = String.valueOf(x);
        int left = 0, right = s.length() - 1;
        
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

**Java 代碼（純數學方案）：**
```java
class Solution {
    public boolean isPalindrome(int x) {
        // 負數和末位是 0 的不是迴文
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false;
        }
        
        int reversed = 0;
        while (x > reversed) {
            reversed = reversed * 10 + x % 10;
            x /= 10;
        }
        
        return x == reversed || x == reversed / 10;
    }
}
```
