### 🎯 考核主題：繼承基礎 (Inheritance) 與雙指針 (Two Pointers)

### Q1: 繼承的核心價值
**【問題】** 為什麼需要繼承？不使用的話會遇到什麼問題？
**【使用者回答】** 「這兩種人員如果有共用的屬性，就沒辦法抽出來而已。」
**【AI 評價】** ✅ 核心概念正確。補充：繼承不僅是抽屬性，更能實現「程式碼重用」與「邏輯統一（例如薪資防呆只要寫在父類別）」。
**【評分】** ⭐⭐⭐ 熟悉

---

### Q2: super() 的語法限制
**【問題】** super() 必須放在建構子的哪一行？
**【使用者回答】** 「Constructor call must be the first statement in a constructor」
**【AI 評價】** ✅ 完全精確。
**【評分】** ⭐⭐⭐ 熟悉

---

### Q3: 私有屬性的存取
**【問題】** 子類別能直接存取父類別的 private 屬性嗎？
**【使用者回答】** 「不行吧，應該透過 super? 有可能兩個名字不一樣」
**【AI 評價】** ⚠️ 觀念稍微模糊。`super()` 是用於「初始化」，但要「存取」必須透過父類別提供的 `public getters`。
**【評分】** ⭐⭐ 會用但需強化

---

### Q4: 雙指針運作邏輯
**【問題】** 當 sum < target 時，為什麼是 left++？
**【使用者回答】** 「因為當 sum < target 時，左邊的需要往右邊靠近」
**【AI 評價】** ✅ 邏輯正確。在排序陣列中，右移 left 指針會讓 sum 變大，更接近 target。
**【評分】** ⭐⭐⭐ 熟悉

### Q5: 實作練習：繼承結構

**【評分】** ⭐⭐ 會用但需強化

### Q6: 實作練習：雙指針演算法
**【要求】** 寫出 Two Sum II 的核心 logic。
**【使用者代碼】**
```java
while (left < right) {
    sum = nums[left] + nums[right];
    if (sum == target) break;
    else if (sum < target) left++;
    else right--;
}
```
**【AI 評價】** ✅ 邏輯完全正確，時間複雜度 O(n)。
**【評分】** ⭐⭐⭐ 熟悉
