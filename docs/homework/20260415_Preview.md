## 🏗️ 1. Java 容器基礎 (Data Structures)

### A. 陣列 (Array) - 固定長度的集合
- **特點**：一旦宣告長度就不能改變。記憶體連續，存取速度最快。
- **語法**：
  ```java
  int[] numbers = {1, 2, 3, 4, 5};
  System.out.println(numbers.length); // 取得長度 (注意：不是方法，沒有括號)
  ```

### B. 動態陣列 (ArrayList) - 會自動變大的陣列
- **來源**：`java.util.ArrayList` (需要 import)。
- **特點**：長度可變。適合不確定資料有多少的情況。
- **常用操作**：
  ```java
  ArrayList<String> names = new ArrayList<>();
  names.add("Alice");       // 新增
  String first = names.get(0); // 取得第一筆 (從 0 開始)
  names.remove(0);          // 刪除第一筆
  int size = names.size();  // 取得目前數量
  ```

### C. 雜湊表 (HashMap) - 鍵值對 (Key-Value)
- **來源**：`java.util.HashMap` (需要 import)。
- **觀念**：就像「字典」或「通訊錄」。你給它一個 **Key (鍵)**，它能瞬間幫你找到 **Value (值)**。
- **常用操作**：
  ```java
  HashMap<Integer, String> studentMap = new HashMap<>();
  studentMap.put(101, "張小明"); // 存入 (Key=101, Value=張小明)
  if (studentMap.containsKey(101)) { // 檢查 Key 是否存在
      String name = studentMap.get(101); // 取得 Value
  }
  ```
- **核心優勢**：在資料量很大時，尋找特定的 Key 速度極快 ($O(1)$)，不需要像 Array 那樣從頭掃描到尾。

## 📊 2. SQL 聚合函數 (Aggregation)

當我們需要從大量資料中計算出「一個結果」時，就會用到聚合函數。

- **`COUNT(*)`**：計算總列數。
- **`SUM(column)`**：計算該欄位的數值總和。
- **`AVG(column)`**：計算該欄位的平均值。
- **`MAX/MIN(column)`**：最大/最小值。

### 關鍵：GROUP BY (分組)
如果你想知道「各部門」的平均薪資，你必須按部門分組：
```sql
SELECT department_id, AVG(salary) 
FROM employees 
GROUP BY department_id;
```

## 🧩 3. LeetCode #1 Two Sum 的優化思路

**今天的暴力法 (Brute Force)**：
```java
// 兩層迴圈：O(n^2)
for(int i=0; i<nums.length; i++) {
    for(int j=i+1; j<nums.length; j++) {
        if(nums[i] + nums[j] == target) return ...;
    }
}
```

**明天的 HashMap 優化法**：
1. 建立一個 HashMap，Key 存「數字」，Value 存「索引 index」。
2. 遍歷一次陣列。
3. 對於目前的數字 `x`，計算 `needed = target - x`。
4. 去 HashMap 裡問：「你有沒有存過 `needed` 這個數字？」
5. 有的話，直接取得它的索引。
6. 沒有的話，把 `x` 和它的索引存進 Map，繼續下一個。
- **效率**：只需要遍歷一次，時間複雜度優化到 **$O(n)$**！
