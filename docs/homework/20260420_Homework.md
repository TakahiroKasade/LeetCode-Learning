# 20260420 晚間自主練習：護理排班津貼計算 (Shift Credit Parser)

這是一題模擬 HIS 系統人事模組的邏輯題，旨在鞏固 LeetCode #13 學習到的「前瞻邏輯」。

## 📝 題目說明

輸入一個代表月份班表的字串 `s`，計算該護理師的總點數。

### 1. 基礎對照表
- `D` = 1.0 點
- `N` = 2.0 點
- `O` (Off) = 0.0 點

### 2. 特殊加成規則
- 如果班表出現 `DN` 序列（白班後接夜班），該個 `D` 的點數從 1.0 變更為 **1.5**。
