## 📝 考核明細與詳解

### 【Java OOP 篇】
**Q1: Class 與 Object 的差別？**
- **學員回答**：Class 是類別，Object 則是物件需要宣告。
- **解析**：正確。Class 是「藍圖/設計圖」，Object 是根據藍圖產出的「實體」。

**Q2: 執行 p2 = p1 後，修改 p2 會影響 p1 嗎？**
- **學員回答**：會的！因為 p1 的地址指向 p2。
- **解析**：正確。這稱為「引用賦值」，兩者在 Stack 中存的是同一個 Heap 地址。

**Q3: 引用型別與基本型別的存放位置？**
- **學員回答**：引用型別在 Heap，基本型別在 Stack。
- **解析**：完全正確。

**Q4: NullPointerException (NPE) 的成因？**
- **學員回答**：變數沒有賦值，卻嘗試調用它。
- **解析**：正確。當一個引用變數的值為 `null`，卻嘗試調用其方法（如 `.length()`）時就會發生。

### 【SQL 進階篇】
**Q5: 子查詢的定義與位置？**
- **學員回答**：像包一層繼續查，通常在 WHERE 或 FROM。
- **解析**：正確。它是嵌套在主查詢內部的 SELECT 指令。

**Q6: 子查詢回傳「單值」與「多值」的差別？**
- **學員回答**：單值用 `=`，多值用 `IN`。
- **解析**：正確。

**Q7: 排除法關鍵字？**
- **學員回答**：NOT IN。
- **解析**：正確。常用於找出沒交集、沒紀錄的資料。

**Q8: 聚合函數的語法位置？**
- **學員回答**：函數名稱後面加括號欄位。
- **解析**：正確。例如 `MAX(salary)`。

### 【演算法邏輯篇】
**Q9: 為什麼需要「前瞻邏輯」(Look-ahead)？**
- **學員回答**：因為要判斷目前位置與下一個位置的關係。
- **解析**：正確。羅馬數字或特殊班表，當前的價值取決於後面的 context。

**Q10: 防禦性編程的條件？**
- **學員回答**：判斷旁邊是否有鄰居。
- **解析**：正確。語法上即為 `if (i < n - 1)`，確保存取下一個索引時不會越界。
