## 📅 15 分鐘快閃考核：逐題比對紀錄

### 1. Java：掛號系統診間存儲選用
- **問題**：固定 5 個診間，該選 Array 還是 ArrayList？
- **您的回答**：我會選用 Array，因為 Array 適合固定數量的，但如果診間數量每天都在改變就會用 ArrayList。
- **標準解析**：**完全正確**。靜態 Array 在記憶體中連續存放，效能最優，適合已知固定上限的場景。
- **評分**：✅ 15/15

### 2. Java：HashMap Key 重複 put 測試
- **問題**：連續 put (101, "A") 與 (101, "B") 後，get(101) 會拿到什麼？
- **您的回答**：拿到 B，key 是唯一的。
- **標準解析**：**完全正確**。這體現了 HashMap 的 **Overwrite (覆蓋)** 特性。
- **評分**：✅ 15/15

### 3. Java：ArrayList 的刪除操作選用
- **問題**：`remove(0)` 與 `remove("物件")` 的差異與建議？
- **您的回答**：用 `remove(0)`。因為 `()` 裡面是用 key 方式，如果用 value 可能會拋出異常，因為有可能兩個 key 的 value 是一樣的。
- **標準解析**：**邏輯正確，但術語需微調**。
    - **修正**：在 List 中我們稱為 **Index (索引)** 和 **Element (元素)**，非 Key/Value。
    - **解析**：`remove(0)` 效率極高（O(1)）；而 `remove("物件")` 必須從頭遍歷搜尋。
- **評分**：⚠️ 10/15 (術語修正建議)

### 4. SQL：WHERE 與 HAVING 的過濾時機
- **問題**：哪一個能篩選 `COUNT(*) > 1`？
- **您的回答**：HAVING，HAVING 是聚合函數，它可以搭配 AVG、COUNT，其他還有什麼我就不曉得了。
- **標準解析**：**正確**。WHERE 跑在分組(GROUP BY)前，HAVING 跑在分組後，因此只有 HAVING 能看到聚合結果。
- **補充**：常見聚合函數包含 `SUM()`、`MAX()`、`MIN()`。
- **評分**：✅ 20/20

### 5. SQL：Self-Join 刪除邏輯
- **問題**：`p1.id > p2.id` 會刪掉誰？Self-join 中文是什麼？
- **您的回答**：被刪掉的是 id 較大的。Self-join 的中文解釋叫什麼？
- **標準解析**：**完全正確**。刪除較大的 ID 代表保留了最早的那一筆。
- **中文解釋**：**自身連接** 或 **自我連接**。
- **評分**：✅ 20/20

- **您的回答**：我會用 ArrayList。
- **標準解析**：**完全正確**。ArrayList 是最通用的批次容器載體。
