### Q1: 手寫 Hash 桶位模擬 (Simple Hash Simulation)

**【問題】**
不使用 Java 內建的 HashMap，手動實作一個桶位系統（陣列 + 鏈表），並處理 Hash 碰撞與重複 Key 的更新。

**【使用者的思考流程】**
- **初期概念**：理解 Key 的唯一性與 Key-Value 對應關係。
- **碰撞處理**：理解「地址相同」不代表「Key 相同」，學習使用 `hashCode() % 10` 定位，並用 `LinkedList` 解決碰撞。
- **邏輯轉折**：在 `addMedicine` 中，學習「先遍歷確認、再決定是否新增」的邏輯。
- **糾結點**：對於 `index * -1` 的正負號處理與迴圈內 `return` 的中斷邏輯感到「怪怪的」，但最終透過運行結果驗證了邏輯正確性。

**【使用者寫的代碼】**
```java
// 地址計算
public static int getBucketIndex(String medicine) {
    int hash = medicine.hashCode();
    int index = hash % 10;
    if(index < 0) { index = index * -1; }
    return index; 
}

// 入庫邏輯
for(DrugEntry entry : bucket) {
    if(entry.drugName.equals(medicine)) {
        entry.count++;
        return; // 關鍵：找到就不再往下執行
    }
}
bucket.add(new DrugEntry(medicine, 1));
```
