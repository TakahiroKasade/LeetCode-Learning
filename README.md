### 運行代碼
大多數代碼可以直接在 Eclipse 或 IntelliJ IDEA 中運行。

#### Eclipse 使用指引：
1. **匯入**：選擇 `Import` -> `Existing Maven Projects` 指向本目錄。
2. **更新**：若有紅線，請對專案點擊 `Maven` -> `Update Project`。
3. **執行**：在包含 `main` 方法的檔案上點擊右鍵 -> `Run As` -> `Java Application`。

## 💡 為什麼開設這個項目？

我用了一年的 AI 輔助編程，導致代碼都是自動生成的。
這個項目的目的是重新掌握 Java，從「看得懂」到「能手寫」。

我的方法：
1. **動手實踐** - 每道題都手寫代碼
2. **深入思考** - 記錄複雜度分析
3. **知識輸出** - 寫詳細的筆記和總結
4. **定期複習** - 確保真正掌握
