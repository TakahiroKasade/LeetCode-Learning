# LeetCode #155 - Min Stack (最小棧)

## 📌 學習筆記 (2026/04/21)

### 1. 核心觀念：輔助棧 (Auxiliary Stack)
*   **問題**：一般的 Stack 只能看到最頂端元素，無法立刻知道最小值。
*   **解法**：使用兩組 Stack 同步操作。
    - `dataStack`: 儲存所有 push 進來的元素。
    - `minStack`: 儲存對應階段的最小值。

### 2. 操作邏輯圖解
假設輸入順序：`5, 3, 7, 2`

| 操作 | DataStack | MinStack (最小值) | 說明 |
| :--- | :--- | :--- | :--- |
| Push 5 | [5] | [5] | 第一次，5 是最小 |
| Push 3 | [5, 3] | [5, 3] | 3 < 5，3 是新的最小 |
| Push 7 | [5, 3, 7] | [5, 3, 3] | 7 > 3，目前的最小依然是 3 (補位) |
| Push 2 | [5, 3, 7, 2]| [5, 3, 3, 2] | 2 < 3，2 是新的最小 |

### 3. Java 關鍵 API
*   `Stack<Integer> stack = new Stack<>();`
*   `.push(val)`: 壓入。
*   `.pop()`: 彈出。
*   `.peek()`: 查看最頂端 (不移除)。
*   `.isEmpty()`: 檢查是否為空。
