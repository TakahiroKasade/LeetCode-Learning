# [167] Two Sum II - Input array is sorted

## 📝 題目描述
給定一個已排序（升序）的整數陣列 `numbers` 和一個目標值 `target`。找出兩個數字，其總和等於目標值。回傳 1-based 的索引。

---

## 💡 解題思路

### 1. 雙指針法 (Two Pointers) - **最優解**
*   **關鍵點**：利用陣列「已排序」的特性。
*   **作法**：
    1.  設置 `left` 指向陣列開始 (0)，`right` 指向陣列結尾 (length-1)。
    2.  計算兩者之和 `sum`。
    3.  如果 `sum == target`：找到答案。
    4.  如果 `sum < target`：代表和太小，將 `left` 右移（增大數值）。
    5.  如果 `sum > target`：代表和太大，將 `right` 左移（減小數值）。
*   **優點**：不需額外空間，效率極高。

---

## 📊 複雜度分析
*   **時間複雜度**：$O(n)$ (最多遍歷一次陣列)
*   **空間複雜度**：$O(1)$ (只使用了固定數量的變數)
