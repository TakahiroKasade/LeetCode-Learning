# LeetCode #206 - Reverse Linked List (翻轉鏈表)

## 📌 學習筆記 (2026/04/21)

### 1. 核心觀念：引用的「轉身」
Linked List 的本質是一串「物件引用」。
原本：`A (next) -> B (next) -> C`
目標：`A <- (next) B <- (next) C (head)`

### 2. 為什麼這題很難？
當你執行 `curr.next = prev;` 時，你等於是把原本指向後面的線「剪斷」了。
如果沒有先把「後面」存起來，你的程式碼就會在 Heap 中迷路。

### 3. 三指標疊代法 (Three Pointers)
請在實作時，腦中想像這三個指針的移動：
- `prev`: 已經翻轉好的部分的頭（最後會變成整串的頭）。
- `curr`: 正在被翻轉的那個苦主。
- `nextTemp`: 苦主原本的下家（暫存用）。

---

### 🎨 畫出你的邏輯 (虛擬碼)

#### **核心四字口訣：卡位、轉身、交棒、前進**

我們將 `ListNode` 想像成一個 **「存放名片的盒子」**，內容是下一家的地址：

1.  **卡位** (`ListNode nextTemp = curr.next`)
    *   **邏輯**：先把下一家的名片備份給臨時工 `nextTemp`。
    *   **目的**：**【保命】** 免得待會轉身後，線斷了找不到人。
2.  **轉身** (`curr.next = prev`)
    *   **邏輯**：把「前一家的名片 (`prev`)」賦值給自己的 `next` 欄位。
    *   **目的**：**【施工】** 真正的翻轉動作，讓箭頭往回指。
3.  **交棒** (`prev = curr`)
    *   **邏輯**：把「目前的自己 (`curr`)」這張名片賦值給 `prev` 盒子。
    *   **目的**：**【走路】** 讓 `prev` 往前走一格，成為下一輪的前任。
4.  **前進** (`curr = nextTemp`)
    *   **邏輯**：把剛才卡位好的名片從 `nextTemp` 拿回來賦值給 `curr`。
    *   **目的**：**【走路】** 讓 `curr` 趕上進度，處理下一個節點。

> [!TIP]
> **區分思維：**
> - Step 2 是在 **「修改資料結構」** (施工)。
> - Step 3 & 4 只是在 **「移動遙控器」** (走路)。

### 🏠 回家演習指南：桌上的「翻轉手術」

今晚回家，請準備：
- **3 個物品**（如：手機、錢包、鑰匙）代表 **[1]、[2]、[3]** 號節點。
- **3 個小標記**（如：三枚銅板，或標籤紙）代表 **`prev`、`curr`、`nextTemp`**。

#### **步驟 0：擺陣**
1. 將物品 1, 2, 3 擺成一排。
2. 將 `curr` 放在 1 號身上；`prev` 放在左邊桌子的空位上 (null)。

#### **步驟 1：卡位 (`nextTemp = curr.next`)**
- **動作**：把 `nextTemp` 銅板放到 2 號身上。
- **口訣**：**「我抓住 2 號了，你 (1 號) 可以放手了！」**

#### **步驟 2：轉身 (`curr.next = prev`)**
- **動作**：把 1 號原本指向 2 號的方向，改為指向左邊的 `prev` (null)。
- **口訣**：**「我 (1 號) 全身轉過來，背對所有人。」**

#### **步驟 3：交棒 (`prev = curr`)**
- **動作**：把原本在左邊空位的 `prev` 銅板，移到 1 號身上。
- **口訣**：**「1 號現在是我的新隊長 (前輩) 了。」**

#### **步驟 4：前進 (`curr = nextTemp`)**
- **動作**：把 `curr` 銅板移到刚才是 `nextTemp` 抓著的 2 號身上。
- **口訣**：**「處理完 1 號，輪到你了，2 號！」**
