## 🏗️ 1. 資料搜索的效能差異：HashMap vs ArrayList

### 🔍 查詢行為
*   **ArrayList**：像是一頁一頁翻書的 **「線性搜尋」**。如果您要找補數，必須對每個元素進行檢查。
    *   **時間複雜度**：$O(n)$
*   **HashMap**：像是查字典索引的 **「哈希搜尋」**。利用 Key 值經過數學運算 (Hash) 直接命中存放位置。
    *   **時間複雜度**：平均 $O(1)$

### 💡 實戰小結
在處理大量資料（如 LeetCode Two Sum）且需要頻繁查找時，絕對優先考慮將資料轉存進 HashMap。

## 📦 2. 型別轉換：Primitive vs Wrapper

在 Java 中，基本型別 (`int`) 與物件型別 (`Integer`) 的轉換稱為：
*   **Autoboxing (裝箱)**：`int` ➔ `Integer`
*   **Unboxing (拆箱)**：`Integer` ➔ `int`

### ⚠️ 資深工程師警示：NullPointerException
*   `int` 絕對不能為 `null`。
*   `Integer` 可以是 `null`。
*   當您試圖將一個為 `null` 的 `Integer` 物件賦值給 `int` 變數時，Java 會在自動拆箱時拋出 **`NullPointerException`**，這是新手最容易忽略的系統漏洞。

## 🏷️ 3. 修飾詞：Static (靜態) 的本質

`static` 是一個「標籤」，代表該成員屬於 **「類別 (Class)」** 而非個人（物件）。

### 🏫 班級公費比喻
*   **Static 變數 (靜態變數)**：就像全班共用的「班費袋子」。任何學生修改了袋子裡的金額，全班看到的都是修改後的新金額。
*   **Instance 變數 (實例變數)**：就像學生自己的「錢包」。每個學生 (`new` 出來的物件) 都有自己獨立的錢包，互不干預。

### 🚀 為什麼 main 是 static？
因為在程式啟動時，JVM 還沒建立任何物件。標記為 `static` 可以讓 JVM 直接透過類別名稱進入程式入口，不需要先 `new` 一個物件。
