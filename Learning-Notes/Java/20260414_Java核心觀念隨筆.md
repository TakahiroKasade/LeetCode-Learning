## 🏗️ 1. 資料搜索與記憶體佈局

### 🔎 查詢行為 (生活化解釋)
*   **ArrayList (線性搜尋)**：時間 $O(n)$ / 空間 $O(n)$。
*   **HashMap (對號入座)**：時間平均 $O(1)$ / 空間 $O(n)$。

### 🧠 記憶體佈局：Stack (棧) vs Heap (堆)
*   **Stack (棧)**：像是隨身口袋，存放 `int` 等基本型別和物件的「提貨單」(Reference)。
*   **Heap (堆)**：像是大倉庫，存放所有的物件實體 (如 `Integer`、`String`、自定義物件)。
*   **結論**：`int` 與 `Integer` 存的位置不同。`int` 直接存數值在 Stack；`Integer` 則是在 Heap 存實體，並在 Stack 存一個指向它的指針。

## 📦 2. 型別轉換：基本型別 (Primitive) vs 包裝類別 (Wrapper)

### 📊 常見型別對照表
| 基本型別 (Primitive) | 包裝類別 (Wrapper Class) | 預設值 (基本型別) |
| :--- | :--- | :--- |
| `int` | `Integer` | `0` |
| `double` | `Double` | `0.0` |
| `boolean` | `Boolean` | `false` |
| `char` | `Character` | `'\u0000'` |
| `long` | `Long` | `0L` |

*   **包裝類別的功用**：
    1.  讓基本型別能以「物件」形式存在，進而存入 `ArrayList` 或 `HashMap`。
    2.  可以存放 `null` 值，代表「資料不存在」。
    3.  提供許多工具方法（例如 `Integer.parseInt("123")`）。

### ⚠️ 資深工程師警示：空指標異常 (NPE)
*   **為什麼 `int` 不能是 `null`？**
    *   `int` 存放在 **Stack (棧)** 記憶體中，它是一個具體的數值空間，必須被填滿二進位資料。
    *   `null` 是一個 **Reference (引用)** 的概念（代表「不指向任何物件」）。
    *   因為 `int` 不是引用，它沒有「指向哪裡」的問題，所以它無法承載 `null` 這個概念。
*   **危險代碼範例：**
```java
public class NPEDemo {
    public static void main(String[] args) {
        Integer box = null;   // 物件可以是 null
        int num = box;       // 會發生 NullPointerException！
        // 原因：Java 試圖做 Unboxing (box.intValue())，但 box 是空的，
        // 就像試圖從一個不存在的袋子裡抽東西。
    }
}
```

## 🏷️ 3. 修飾詞：Static (靜態) 的本質

### 🏠 靜態項目 (Static) vs 實例項目 (Instance)
*   **Static (靜態)**：就像班費。**不需要 `new` 物件**。適用於工具類功能（如：計算、啟動入口）。
*   **Instance (實例)**：就像個人錢包。**一定要透過 `new` 建立物件**。適用於描述個別對象的屬性（如：銀行帳戶餘額、員工姓名）。

#### **更深入理解 Instance 的用法 (雞蛋糕理論)：**
1.  **類別 (Class)**：是一個「設計圖」或「模具」。它規定了屬性（口味、售價）和行為（被咬一口）。
2.  **實例 (Instance)**：是根據設計圖產出的「實體物件」。
3.  **具體用法範例**：
    ```java
    // 1. 定義設計圖 (Class)
    class Cake {
        String flavor; // 口味 (Instance 變數)
        void beEaten() { System.out.println(flavor + " 蛋糕被吃了！"); }
    }
    
    // 2. 產生實體 (Instance)
    Cake c1 = new Cake(); 
    c1.flavor = "奶油";  // 設定這顆蛋糕的私有屬性
    
    Cake c2 = new Cake();
    c2.flavor = "巧克力";
    
    // 3. 呼叫行為
    c1.beEaten(); // 只有 c1 的屬性被存取
    ```
