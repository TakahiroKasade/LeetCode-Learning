## 1. 巢狀迴圈 (Nested Loop) - 九九乘法表的關鍵
要在程式中輸出一個二維的結構（例如 9x9），我們需要「迴圈裡面套迴圈」。

```java
// 外層迴圈代表「列」(例如：1 到 9 乘法)
for (int i = 1; i <= 9; i++) {
    // 內層迴圈代表「行」(例如：乘數 1 到 9)
    for (int j = 1; j <= 9; j++) {
        // 這邊是執行代碼的地方
        System.out.print(i + " * " + j + " = " + (i*j) + "\t");
    }
    System.out.println(); // 內層跑完一輪代表一行結束，要換行
}
```
*   **思考點**：內層迴圈跑完 9 次，外層才跑 1 次。這就是為什麼它能呈現「橫向增長」的原因。

---

## 2. for 與 while 的選擇
*   **for 迴圈**：適用於「已知次數」的情況（如：跑 100 次、遍歷 10 個數字）。
*   **while 迴圈**：適用於「滿足特定條件才停止」的情況（如：讀取檔案直到最後一行、密碼輸入錯誤持續要求輸入）。

---

## 3. 明日手寫心理準備
*   **九九乘法表**：不要去背代碼，而是思考：當 `i=2` 時，內層的 `j` 是如何從 1 跑到 9 的。
*   **對稱感**：注意 `print` (不換行) 與 `println` (換行) 的精準切換。
