# SQL 進階練習：事務處理 (Transaction) - 2026-04-30

## 🏥 領藥交易場景
現在有兩張表：
1. `patient_balance` (病人餘額)：`patient_id`, `balance`
2. `medicine_stock` (藥品庫存)：`med_id`, `stock_count`

### 📊 初始資料
*   病人 P001 餘額：1000 元
*   感冒藥 M01 庫存：10 盒

---

## 🛠️ 實作任務：完成領藥交易流程
**任務描述**：病人 P001 購買一盒感冒藥，價值 200 元。

請寫出一段 SQL 腳本來模擬這個過程：
1.  **開始事務**。
2.  **更新 A**：扣除病人 P001 的餘額 200 元。
3.  **更新 B**：扣除感冒藥 M01 的庫存 1 盒。
4.  **模擬成功**：假設一切順利，請執行「正式提交」。
5.  **模擬失敗**：假設在更新 B 時發生錯誤，請寫出「回滾」的指令。

---

## ✍️ 請在下方寫下你的 SQL 語法：

### 1. 領藥流程 (成功路徑)：
```sql
-- 1. 開始事務
START TRANSACTION;
-- 2. 扣款
UPDATE patient_balance SET balance = balance - 200 WHERE patient_id = 'P001';
-- 3. 扣庫存
UPDATE medicine_stock SET stock_count = stock_count - 1 WHERE med_id = 'M01';
-- 4. 提交
COMMIT;
```

### 2. 回滾指令 (失敗路徑)：
```sql
-- 只要發生錯誤，執行哪一行可以讓錢退回來？
```
ROLLBACK;
