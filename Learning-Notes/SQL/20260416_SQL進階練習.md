## 題型一：找出重複的電子郵件 (LeetCode #182)

### 📋 題目描述
這是一張 `Person` 表，包含 `id` 和 `email`。請寫出一個 SQL 查詢，找出所有重複的電子郵件。

**範例資料 (Person Table):**
| id | email |
| :--- | :--- |
| 1 | a@b.com |
| 2 | c@d.com |
| 3 | a@b.com |

**預期輸出:**
| Email |
| :--- |
| a@b.com |

### 🛠️ 實作思路 (Tips)
1. 使用 `GROUP BY email` 把相同的信箱分在一起。
2. 使用 `COUNT(email)` 來計算每個信箱出現的次數。
3. 使用 `HAVING` 來篩選出次數 > 1 的結果。

### ✍️ 我的解答
```sql
-- 請在此處輸入你的 SQL 語句
SELECT email
FROM　Person
GROUP BY email HAVING COUNT(email) > 1;

```

## 題型二：刪除重複的電子郵件 (LeetCode #196)

### 📋 題目描述
請寫出一個 SQL 語句，**刪除** `Person` 表中重複的電子郵件，只保留每個電子郵件中 `id` 最小的那個。

**注意**：這題要求使用 `DELETE` 語句，而不是 `SELECT`。

**範例資料 (執行前):**
| id | email |
| :--- | :--- |
| 1 | john@example.com |
| 2 | bob@example.com |
| 3 | john@example.com |

**預期結果 (執行後):**
| id | email |
| :--- | :--- |
| 1 | john@example.com |
| 2 | bob@example.com |

### 🛠️ 實作思路 (Tips)
這題有兩種常見解法：
1. **Self Join (推薦)**：將表與自己進行連接 (`Person p1, Person p2`)，當 `p1.email == p2.email` 且 `p1.id > p2.id` 時，刪除 `p1`。
2. **子查詢 (Subquery)**：刪除 ID 不在 (NOT IN)「每個 Email 的最小 ID 清單」中的所有紀錄。

#### 👁️ 視覺化邏輯解析 (Self Join)
在 `FROM Person p1, Person p2` 中，我們定義了兩個**角色**：
- **p1 (嫌疑對象)**：我們想要檢查並刪除的目標。
- **p2 (參考座標)**：用來證明 p1 是重複項的證據（相同的 Email 但更小的 ID）。

| p1 角色 (嫌疑犯) | p2 角色 (證據) | 判斷邏輯 | 動作 |
| :--- | :--- | :--- | :--- |
| id:3, john@x.com | id:1, john@x.com | Email 相同且 p1.id > p2.id | **把 p1(3) 給刪了** |

---

### ✍️ 解法一：Self Join (效能較好)
這是我們剛剛討論的方法，透過兩表連接直接找出要刪除的列。
```sql
DELETE p1 FROM Person p1, Person p2
WHERE p1.email = p2.email AND p1.id > p2.id;
```

### ✍️ 解法二：子查詢 (Subquery)
如果不習慣 Join，可以用「篩選出要留下的，其餘刪掉」的邏輯。
1. `SELECT MIN(id) FROM Person GROUP BY email`：找出所有該留下的 ID。
2. `DELETE FROM Person WHERE id NOT IN (...)`：刪掉不在此清單中的 ID。

```sql
DELETE FROM Person 
WHERE id NOT IN (
    SELECT min_id FROM (
        SELECT MIN(id) AS min_id 
        FROM Person 
        GROUP BY email
    ) as tmp
);
```
*(注意：MySQL 要求在子查詢中多包一層 `as tmp` 才能對同一張表執行刪除)*

## 📌 今日必記 MySQL 語法
```sql
-- 分組統計範例
SELECT column, COUNT(*) 
FROM table 
GROUP BY column 
HAVING COUNT(*) > 1;

-- 刪除範例 (Self Join)
DELETE p1 FROM Person p1, Person p2 
WHERE p1.email = p2.email AND p1.id > p2.id;
```
