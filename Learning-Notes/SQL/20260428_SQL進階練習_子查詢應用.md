# SQL 進階練習：子查詢應用 (2026-04-28)

## 🏥 醫院資料庫場景
目前有兩張表：
1. `departments` (部門表)：`dept_id`, `dept_name`, `location`
2. `staff` (員工表)：`staff_id`, `name`, `salary`, `dept_id`

### 📊 範例資料
**departments:**
| dept_id | dept_name | location |
| :--- | :--- | :--- |
| 1 | Cardiology (心臟科) | 3F |
| 2 | Pediatrics (兒科) | 5F |

**staff:**
| staff_id | name | salary | dept_id |
| :--- | :--- | :--- | :--- |
| S001 | 王醫師 | 80000 | 1 |
| S002 | 李護理師 | 50000 | 1 |
| S003 | 張醫師 | 75000 | 2 |

---

## 🛠️ 實作任務

### 任務一：跨表更新 (Update with Subquery)
**情境**：醫院決定幫「心臟科 (Cardiology)」的所有員工調薪 5%。
**要求**：請寫出一個 `UPDATE` 語句，使用子查詢找出 `Cardiology` 的 `dept_id`，並更新 `staff` 表中對應員工的 `salary`。

### 任務二：條件插入 (Insert with Select)
**情境**：醫院要建立一張「高薪員工備份表 (`high_salary_backup`)」。
**要求**：
1. 先建立 `high_salary_backup` 表（包含 `name` 和 `salary` 兩個欄位）。
2. 使用 `INSERT INTO ... SELECT` 語法，將 `salary > 70000` 的員工姓名與薪資一次性存入該表。

---

## ✍️ 請在下方寫下你的 SQL 語法：

### 任務一回答：
```sql
-- 

UPDATE staff
SET salary = salary *1.05
WHERE  dept_id 
IN (SELECT dept_id FROM departments WHERE dept_name='Cardiology')
```

### 任務二回答：
```sql

CREATE TABLE high_salary_backup(
    name VARCHAR(20),
    salary INT
);

INSERT INTO high_salary_backup (
    name, salary
)
SELECT name, salary
FROM staff
WHERE salary > 70000;
```
