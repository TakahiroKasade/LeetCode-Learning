# SQL 進階練習：多表 JOIN 與 HIS 系統應用

## 📅 日期：2026/04/21
## 🎯 學習目標：掌握多張資料表的關聯 (INNER JOIN) 與資料篩選

---

### 📊 模擬資料庫結構參考
在寫 SQL 之前，請務必先看清楚欄位之間的關聯 (FK)：

1. **PERSON (人員主檔)**
   - `person_id` (PK)
   - `name` (姓名)

2. **ADDRESS (住址表)**
   - `address_id` (PK)
   - `person_id` (FK -> PERSON.person_id)
   - `city` (城市)
   - `district` (行政區)

3. **HOSPITAL (醫院表)**
   - `hosp_id` (PK)
   - `hosp_name` (醫院名稱)

4. **DEPARTMENT (科別表)**
   - `dept_id` (PK)
   - `hosp_id` (FK -> HOSPITAL.hosp_id)
   - `dept_name` (科別名稱)

5. **DOCTOR (醫師表)**
   - `dr_id` (PK)
   - `person_id` (FK -> PERSON.person_id)
   - `dept_id` (FK -> DEPARTMENT.dept_id)
   - `experience_years` (年資)

---

### ✍️ 實戰練習區

#### 題目 1：兩表 JOIN (查詢人員與住址)
需求：查詢所有人員的「姓名」與其對應的「城市 (City)」與「行政區 (District)」。

```sql
-- 請在此輸入你的 SQL
關聯table:PERSON、ADDRESS
SELECT p.name , a.city, a.district
FROM PERSON p 
INNER JOIN ADDRESS a
ON p.person_id = a.person_id

```

#### 題目 2：三表 JOIN (查詢醫院與科別)
需求：列出每間醫院名稱 (`hosp_name`) 以及該醫院下所有的科別名稱 (`dept_name`)。

```sql
-- 請在此輸入你的 SQL
SELECT hosp_name , d.dept_name
FROM Hospital h
LEFT JOIN Department d ON  h.hosp_id = d.hosp_id
```

#### 題目 3：四表 JOIN (HIS 醫師完整資訊)
需求：顯示「醫師姓名、所屬科別、所屬醫院、醫師年資」。

```sql
-- 請在此輸入你的 SQL
SELECT p.name ,d.experience_years, de.dept_id, h.hosp_name
FROM PERSON p
LEFT JOIN DOCTOR d on d.person_id = p.person_id
LEFT JOIN DEPARTMENT  de on de.dept_id = d. dept_id
LEFT JOIN HOSPITAL h on h.hosp_id = de.hosp_id

```
