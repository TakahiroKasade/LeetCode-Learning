# 🗄️ SQL 基礎入門 (MySQL)

明天我們將在 LeetCode 上實作 SQL 查詢。如果您在公司只用過自然語言叫 AI 寫 SQL，請今晚務必熟悉以下標準語法。

---

## 1. 查詢的核心語系：SELECT ... FROM
這是所有 SQL 的起手式，就像 Java 的 `main` 方法一樣。
```sql
SELECT column1, column2 
FROM table_name;
```
*   **技巧**：若要全選，用 `*`。但實務上（為了效能與安全），建議只選出需要的欄位。

---

## 2. 條件過濾：WHERE
這相當於 Java 的 `if` 判斷。
```sql
SELECT * FROM products
WHERE price > 100 AND category = 'Electronics';
```
*   **常用符號**：`=`、`!=` (或 `<>`)、`>`、`<`、`>=`、`<=`、`LIKE` (模糊搜尋)。
*   **LeetCode 暖身**：明天的題目會考「尋找 Big Countries」，重點就在於把面積(area)或人口(population)的條件寫進 `WHERE`。

---

## 3. 排序結果：ORDER BY
```sql
SELECT name, salary 
FROM employees
ORDER BY salary DESC; -- DESC (倒序:大到小) / ASC (正序:小到大)
```

---

## 4. 今日關鍵筆記：GROUP BY & HAVING
這是您今天考核落點的部分，請重點預習：
*   **GROUP BY**：用來「分堆」。例如：按部門分組。
*   **HAVING**：針對「分完堆」後的結果做篩選。
*   **口訣**：一般條件用 `WHERE`，統計結果（如 COUNT, SUM）的篩選用 `HAVING`。

```sql
-- 找出員工人數大於 5 人的部門
SELECT department, COUNT(*) 
FROM employees
GROUP BY department
HAVING COUNT(*) > 5;
```
