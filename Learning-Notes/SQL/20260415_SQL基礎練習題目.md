## 📝 題目一：Big Countries (LeetCode #595)

### 📖 題目描述
我們定義一個國家如果是「大國」，必須符合以下 **其中一個** 條件：
1. 面積 (area) 至少 3,000,000 $km^2$。
2. 人口 (population) 至少 25,000,000 人。

請找出所有「大國」的 **名稱 (name)**、**人口 (population)** 和 **面積 (area)**。

### 📊 表格結構：`World`
| Column Name | Type | Description |
| :--- | :--- | :--- |
| name | varchar | 國家名稱 (Primary Key) |
| continent | varchar | 洲 |
| area | int | 面積 |
| population | int | 人口 |
| gdp | long | 國內生產總額 |

### ✍️ 我的解答
```sql
-- 請在此處輸入你的 SQL 查詢
SELECT name, population, area
FROM World
WHERE area>=3000000 OR population >=25000000;
```

## 📝 題目二：Recyclable and Low Fat Products (LeetCode #1757)

### 📖 題目描述
我們要找出那些既是「低脂」又是「可回收」的產品。
- `low_fats` 為 'Y' 代表是。
- `recyclable` 為 'Y' 代表是。

請找出符合上述兩個條件的 **產品 ID (product_id)**。

### 📊 表格結構：`Products`
| Column Name | Type | Description |
| :--- | :--- | :--- |
| product_id | int | 產品 ID (Primary Key) |
| low_fats | enum | 'Y' (是) / 'N' (否) |
| recyclable | enum | 'Y' (是) / 'N' (否) |

### ✍️ 我的解答
```sql
-- 請在此處輸入你的 SQL 查詢
```
select  product_id
from Products
where low_fats='Y' and recyclable = 'Y';
